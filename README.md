How to use: 

1. query a file with the columns in this order: Timestamp, Longitude, Latitude

2. Find the SRTM-GL1 GEOTIFF tiles that you need. Tip: Download surrounding tiles too. You may run into less problems that way.

3. Combine them with merger.py to create a merged TIF file.

4. Run Finder.py by specifying your input file and TIF elevation data.

5. Run ElevationAnalysis.py to generate the slope column. The file address at the top should be "SLOPELESS_CSV_ADDRESS" and ensure that your string is r"filepath". There are many options to output histograms and the map. The script can also be used to generate visualizations from files with an existing slope column if you use "POST_SLOPE_CSV_ADDRESS". Ensure that only Slopeless or Post Slope is entered, never both.

6. Run SlopeSmoother.py if you want to smooth by moving average or by distance.

AltitudeViewer.py is a Streamlit dashboard for visualizing elevation data generated by Finder.py. Will probably be pretty laggy for large files.
